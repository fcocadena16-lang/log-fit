FIT LOG PWA - versión 1

Archivos listos para GitHub Pages.

1. Crea un repositorio (por ejemplo: fit-log).
2. Sube TODO el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub: Settings > Pages > Deploy from a branch > main / root.
4. Abre la URL publicada en Safari en el iPhone.
5. Compartir > Añadir a pantalla de inicio.
6. Abre una vez con Internet para que el service worker guarde la interfaz localmente.
7. Después prueba Wi-Fi, datos celulares y modo avión.

IMPORTANTE:
- Los datos se guardan actualmente SOLO en IndexedDB del dispositivo/navegador.
- Borrar los datos de Safari puede borrar el historial.
- La sincronización/respaldo en nube se agregará en una fase posterior.
